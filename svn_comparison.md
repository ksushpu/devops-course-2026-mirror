## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

**Git:** ветка — это просто указатель на коммит (файл ~41 байт). Создаётся мгновенно, локально, без копирования файлов.

**SVN:** ветка — это отдельная директория в репозитории. Создаётся на сервере, требует сети и по сути является коммитом. Переключение — перекачивание файлов.

---

## 2. Можно ли в SVN сделать коммит без интернета?

**Нет.** SVN — централизованная система: история хранится только на сервере, а `svn commit` пишет прямо туда. Без сети коммит невозможен.

(В Git — можно: коммит создаётся локально, `push` — отдельно.)

---

## 3. Когда SVN предпочтительнее Git?

- Большие бинарные файлы (PSD, видео) + блокировки `svn lock`
- Строгий централизованный контроль и аудит (банки, госсектор)
- Частичный checkout и права доступа к отдельным папкам
- Простые линейные процессы без ветвления
- Legacy-инфраструктура, где миграция дорога
